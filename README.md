# Accident Detection in Highways

## Project Overview

This project presents an automated accident detection system for detecting possible vehicle collisions from traffic videos.

The system uses YOLO11n for vehicle detection and a rule-based accident detection algorithm that analyzes detected vehicles and collision-related signals.

This project was developed as Stage 1 of the Accident Detection project.

## Objectives

- Detect vehicles from traffic videos using YOLO11n.
- Automatically identify possible vehicle collisions.
- Reduce manual inspection of traffic videos.
- Process multiple videos automatically for evaluation.
- Identify the approximate time of a detected accident.
- Provide accident detection results through a web interface.
- Evaluate the system using standard performance metrics.

## Accident Detection Algorithm

The system uses YOLO11n to detect vehicles in individual video frames.

The detected vehicle positions are analyzed using multiple collision-related conditions. These conditions are combined to determine whether a possible accident event has occurred.

Important parameters used in the detection algorithm include:

MAX_PAIR_DISTANCE = 135  
CONTACT_GAP = 18  
CONTACT_IOU = 0.02  
MIN_EVENT_SCORE = 5  
MIN_INDEPENDENT_SIGNALS = 2

The parameters were adjusted during testing to improve accident detection performance.

### Accident Confidence

The displayed Accident Confidence is a heuristic score generated by the accident-detection logic.

It should not be interpreted as a calibrated probability and is different from the YOLO object-detection confidence.

## Automated Evaluation

The file `stage1_100_video_automation.py` contains the main Stage 1 automated accident-detection and evaluation pipeline.

The evaluation uses ground-truth information containing:

- Video name
- Accident / Non-Accident classification
- Accident timestamp

The system evaluates predictions using:

- True Positive (TP)
- True Negative (TN)
- False Positive (FP)
- False Negative (FN)

These values are used to calculate the final performance metrics.

## Dataset 1 Testing

Additional testing was performed using the Dataset 1 testing pipeline.

The testing setup included:

- Target FPS: 15
- YOLO input resolution: 640 × 640
- Ground-truth classes: ACCIDENT and NON_ACCIDENT

The file `stage1_dataset1_test.py` was used for additional Dataset 1 testing.

Selected videos were also manually reviewed to study different traffic situations, including:

- Vehicle collisions
- Divider impacts
- Barrier or fence contact
- Heavy traffic
- Distant accidents
- Low-visibility scenarios
- Cases where vehicle contact did not necessarily represent an accident

## Web Interface

The project includes a web interface implemented in `app.py`.

The interface is designed to allow a user to:

- Upload a traffic video
- Run accident detection
- View the processed result
- Identify the detected accident timestamp
- View the first detected event
- View the detection result and associated score
